# Nekosia API

Nekosia is a free, keyless anime-image REST API serving cute anime 'neko' (catgirl) imagery and related metadata, backed by the provider's own Booru. Responses are JSON with rich metadata including dominant colors, image variants, dimensions, tags, ratings, and source attribution.

- **Provider:** https://nekosia.cat/
- **Documentation:** https://nekosia.cat/documentation?page=introduction
- **Base URL:** https://api.nekosia.cat/api/v1
